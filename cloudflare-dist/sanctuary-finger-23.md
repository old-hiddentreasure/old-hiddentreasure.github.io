# 23. 有次第、有範圍的練習

一開始練習下單要限制自己自由度，從最小範圍開始熟練，再逐漸擴展出去。剛開始練習時，訊號沒來就絕不出手，熟練後再變成多策略，這樣長久其實都能賺錢。等於說先設好框架，球進好球帶再打（巴菲特語），而不是無限地去追逐外境。比如說：

• **(a) 基礎目標（單策略）：週獲利**。從一口單開始，規定只能做多、只能低接。風控與停利：停損 = 停利 = 1R = 200 ticks；保護機制：獲利超過 1/2 R 啟動保本機制；部位上限：當日最大虧損 = 3R。連續做 1-2 個月，再進入進階。
• **(b) 進階目標（多策略）：雙週獲利**。
  ▪ **策略 A（下跌抄底 / 低接）**：方向限制：只能做多；進場模式：只能低接（左左）；風控與停利：停損 = 停利 = 1R = 200 ticks；保護機制：獲利超過 1/2 R 啟動保本機制。
  ▪ **策略 B（追突破）**：方向限制：只能做多；進場模式：突破做多（右右）；風控與停利：停損 = R = 100 ticks、停利 > 2R；出場依據：樞紐轉折停利。
  ▪ **策略 C（突破後拉回 / 轉強）**：方向限制：只能做多；進場模式：轉強做多（右左）；風控與停利：停損 = R = 300 ticks、停利 = 1R；保護機制：獲利超過 1/2 R 啟動保本機制。
